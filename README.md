# 匹小将

一拍尽兴，小将同行。

## 运行微信小程序

打开微信开发者工具，导入仓库根目录，保留 `project.config.json` 里的 AppID，点击「编译」。小程序源码位于 `pikdink/`，无需安装 npm 依赖。

首页提供推荐和搜索，底部栏包含首页、资讯、教学、场地、装备、我的六个入口。可以按分类浏览示例内容，进入详情并收藏，再到「我的收藏」查看。收藏保存在当前设备。

## 目录

| 路径 | 用途 |
| --- | --- |
| `pikdink/pages/` | 九个页面及内容频道共用的页面逻辑 |
| `pikdink/components/` | 六栏底部导航和内容卡片 |
| `pikdink/services/` | 示例内容、搜索与本地收藏 |
| `pikdink/assets/` | 小程序使用的图片 |
| `frontend/`、`design/` | 网页原型和设计稿 |
| `PRD.md` | 产品需求与后端接口约定 |

当前为前端框架。微信登录、真实内容接口和跨端收藏同步待接入。
